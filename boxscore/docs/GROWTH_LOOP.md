# Growth Loop

Boxscore gets smarter by recording what happened during real analyses.

1. User asks a variance question.
2. Tools load available data.
3. Variance engine computes financial movement.
4. Gap engine identifies missing data, weak evidence, and low-confidence areas.
5. Question engine asks the operator targeted questions.
6. Operator answers create specific memories when useful.
7. Evolution engine updates the capability backlog.
8. Future analyses use accumulated memory and improved data coverage.

The loop is proposal-first. It does not silently alter code, delete data, call external providers, or deploy.
